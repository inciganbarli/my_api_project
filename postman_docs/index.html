Movie API Postman Documentation

This is a separate documentation page kept outside the GitHub project, as requested.

Overview

The API provides movie management with JWT authentication, GitHub OAuth, Redis caching, Swagger docs, and GraphQL support.

Primary live URL: https://my-api-n6ed.onrender.com

Swagger UI: https://my-api-n6ed.onrender.com/api-docs

Quick Start

  1. Import the collection file from my_api/postman/Movie_API.postman_collection.json.
  2. Choose the environment file for local or production usage.
  3. Run Register and then Login.
  4. Use the saved {{token}} value for protected requests.

Included Endpoints

  • Auth: Register, Login, Profile, GitHub OAuth
  • Movies: list, search, get by ID
  • Protected Movies: create, update, delete
  • GraphQL: queries and mutations

Example Request

POST https://my-api-n6ed.onrender.com/register
Content-Type: application/json

{
  "username": "john_doe",
  "email": "john@example.com",
  "password": "password123"
}

How to Publish This in Postman

  1. Open Postman and import the collection JSON file.
  2. Click Publish in the collection menu.
  3. Choose a title and description, then create the documentation page.
  4. Copy the generated public URL for your README or portfolio.
