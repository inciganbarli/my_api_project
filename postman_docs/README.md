# Postman Documentation Notes

This folder is kept outside the GitHub project to avoid pushing the Postman docs into the main repo.

Use these files:
- index.html — browser-friendly documentation summary
- ../my_api/postman/Movie_API.postman_collection.json — the collection to import into Postman

To publish the real Postman docs page:
1. Open Postman.
2. Import the collection JSON file.
3. Click Publish in the collection menu.
4. Copy the generated public documenter URL.
